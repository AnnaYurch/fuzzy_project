1. Че за нечеткая величина?
Обычное число — это точка на прямой (например, ровно 5.0).
Нечеткое число — это понятие вроде "примерно 5". Оно описывается функцией принадлежности
μ(x), которая для любого значения x возвращает число от 0 до 1 (насколько сильно 
x принадлежит этому "примерно 5").
В твоем варианте функцией принадлежности выступает нормальное распределение.
Оно полностью задается двумя параметрами: 
- x0​ (центр): самое вероятное значение (вершина колокола). Для него μ(x0)=1.
- σ (сигма, разброс): мера нечеткости. Чем больше σ, тем шире и более "размыто" число.

2. Арифметика нечетких чисел
Когда мы складываем два нечетких числа A = (x0A, σA) и B=(x0B, σB), их центры складываются, а нечеткость (дисперсия) тоже растет. 
Формулы простые:
Сложение: новый центр = x0A + x0B, новая сигма = корень из (σA^2 + σB^2)
Вычитание: новый центр = x0A - x0B, новая сигма = корень из (σA^2 + σB^2)
Умножение на число k: новый центр = k ⋅ x0, новая сигма = ∣k∣ ⋅ σ

3. Генерация нечетких чисел (перепроверить)
Задание требует генерировать их не просто через готовую функцию numpy.random.normal, а через формулы аппроксимации (сумма равномерно распределенных случайных величин). Это классический метод (интегральная теорема Муавра-Лапласа), который ты реализуешь в коде, чтобы показать преподавателю, что ты понимаешь, откуда берется нормальное распределение.

4. Кластерный анализ нечетких величин
У тебя будет 100–300 нечетких чисел (пар (x0, σ)). Кластеризация — это разбиение их на группы (кластеры) так, чтобы числа внутри одной группы были "похожи", а между группами — отличались.
Как измерить "похожесть"? Мы считаем расстояние между двумя нечеткими числами как обычное евклидово расстояние между их параметрами на плоскости:
Чем меньше расстояние, тем ближе числа. Алгоритм (например, K-Means из scikit-learn) использует это расстояние для группировки.

2: Способ представления нечеткой величины
Где: libs/fuzzy_number.py
Идея: Создаем класс FuzzyNumber.
Атрибуты: x0 (float), sigma (float).
Метод get_membership(x): возвращает значение exp(− (x − x0)^2 / (2⋅σ^2)).
Метод plot(): строит график этого "колокола" с помощью matplotlib.

3: Ввод, вывод и логирование
Где: libs/logger.py и main.py
Идея: В logger.py пишем класс или функции log_info(message) и log_error(message), которые используют встроенный модуль logging. Они одновременно выводят текст в консоль и дописывают его в файл logs/app.log с датой и временем. В main.py мы вызываем эти функции при каждом действии (например, "Сгенерировано 150 чисел").

4: Манипулирование (арифметика)
Где: libs/fuzzy_ops.py
Идея: Набор независимых функций, которые принимают объекты FuzzyNumber и возвращают новый объект FuzzyNumber.
add(a: FuzzyNumber, b: FuzzyNumber) -> FuzzyNumber
subtract(a, b) -> FuzzyNumber
multiply_by_scalar(a, k) -> FuzzyNumber
compare(a, b): возвращает, какое число "больше" (обычно сравнивают по центру x0, а при равенстве — по меньшей нечеткости σ).

5: Генерация набора (100–300 шт.)
Где: libs/generator.py
Идея: Функция generate_fuzzy_set(count: int) -> list[FuzzyNumber].
Внутри: цикл, который генерирует равномерные случайные числа, суммирует их и применяет формулу аппроксимации из твоего задания (ту самую с ωn и поправочными членами), чтобы получить стандартное нормальное число.
Затем это число масштабируется: x′ = σ_target ⋅ η + x0_target.
Результат сохраняется в список и логируется.

6: Кластерный анализ
Где: libs/clustering.py
Идея:
Функция calculate_distance(a: FuzzyNumber, b: FuzzyNumber): реализует формулу евклидова расстояния между 
(x0, σ).
Функция perform_clustering(fuzzy_list, n_clusters): преобразует список объектов FuzzyNumber в матрицу NumPy формы (N, 2) (где столбцы — это x0 и σ), передает её в sklearn.cluster.KMeans, а затем возвращает список, где каждому исходному нечеткому числу присвоен номер кластера (0, 1, 2...).
